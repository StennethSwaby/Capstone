==============================
TurtleBot3 + SLAM Toolbox Setup Notes
==============================

SECTION 1 — HOW TO GET THE TURTLEBOT3 UP AND RUNNING WITH SLAM TOOLBOX
-----------------------------------------------------------------------

A. On the TurtleBot (Robot PC)
1. Connect the robot to power and ensure the LiDAR (LDS) and Raspberry Pi/NUC are connected.
2. SSH into the robot or open a terminal directly on it.
3. Set up environment variables:
   export TURTLEBOT3_MODEL=burger        # or waffle / waffle_pi
   export ROS_DOMAIN_ID=0
   export ROS_LOCALHOST_ONLY=0
4. Launch the TurtleBot3 bringup:
   ros2 launch turtlebot3_bringup robot.launch.py
   - This starts the base motors, IMU, and LiDAR (hlds_laser_publisher).
   - You should see messages like:
     Succeeded to open the port(/dev/ttyACM0)!
     Run!
5. Verify sensors are publishing:
   ros2 topic list | grep scan
   You should see /scan in the list.


B. On the Desktop (Your Laptop)
1. Make sure you’re on the same Wi-Fi network as the robot.
2. In your terminal:
   export ROS_DOMAIN_ID=0
   export ROS_LOCALHOST_ONLY=0
3. Launch SLAM Toolbox with the working custom launch file:
   ros2 launch slam_toolbox_bringup slam_toolbox_robot.launch.py \
     use_sim_time:=false base_frame:=base_footprint scan_topic:=/scan
   - This starts SLAM Toolbox (async_slam_toolbox_node) and RViz2 automatically.
   - You should see the map forming dynamically as the robot moves.
4. Start keyboard teleoperation (optional):
   ros2 run teleop_twist_keyboard teleop_twist_keyboard
   - Use the keys i, j, k, l, etc., to move the robot.
5. When mapping is complete, save the map:
   ros2 run nav2_map_server map_saver_cli -f ~/maps/tb3_map
   This generates tb3_map.pgm and tb3_map.yaml.


C. RViz2 Configuration Checklist
- Fixed Frame: map
- Add:
  - TF
  - Map → Topic: /map → QoS: Reliable + Transient Local
  - LaserScan → Topic: /scan → QoS: Best Effort
- (Optional) Add RobotModel and Odometry for visualization.
- Make sure the map is gray/white (Color Scheme = map, Alpha = 1.0).
- As you move the robot, the map should grow dynamically.
